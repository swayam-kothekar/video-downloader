# Release Changelog

## Major UI Revamp
- Redesigned Interface: A complete overhaul of the user interface featuring modern layouts, smooth animations, radial gradient backgrounds, and refined typography.
- Unified Navigation: Added a side drawer for easier navigation between the download dashboard, completed downloads, settings, and about screens.
- Flexible Theme Controls: Seamlessly switch between Light Mode, Dark Mode, or follow your system's default preference.

## New Features
- Parallel Downloads: Download multiple video or audio files simultaneously with individual progress bars and download speed indicators.
- High-Resolution Support: Download videos in full quality (1080p, 2K, and 4K) with audio automatically merged in the background.
- Smart Download Resume: Interrupted downloads from network drops or closing the app can be resumed from where they left off instead of starting over.
- Wi-Fi Only Mode: Save cellular data by enabling an option that automatically pauses downloads on mobile networks and resumes on Wi-Fi.
- Subtitle Downloads: Download closed captions and subtitle tracks (.srt/.vtt files) automatically along with your videos.
- Storage Management: View how much temporary storage download cache is consuming and clear it with a single tap in settings.
- In-App Update Alerts: The app automatically checks for newer updates on startup and notifies you with update details.

## Improvements and Fixes
- Private & Permission-Free Storage: Fully updated to modern Android storage standards. Videos save directly to your public Downloads folder without requesting broad or intrusive access permissions to your private files.
- Download Conflict Resolution: Fixed errors that occurred when trying to download the same video in multiple qualities concurrently.
- General Stability: Resolved random download failures and optimized memory usage during file processing.
